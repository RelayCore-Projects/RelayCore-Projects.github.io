# RelayCore Projects

Source code of the RelayCore Projects portfolio site, built with Astro.

Work in progress. Planned address: https://relaycore-projects.github.io

## Development

Requires Node.js 22.22 or later.

| Command           | What it does                                  |
| :---------------- | :-------------------------------------------- |
| `npm install`     | Installs the dependencies                     |
| `npm run dev`     | Starts a local dev server at `localhost:4321` |
| `npm run build`   | Builds the static site into `dist/`           |
| `npm run preview` | Serves the built site locally                 |

## Stack

- Astro (static site generator)
- Planned: deployment to GitHub Pages with GitHub Actions
- Planned: Playwright smoke tests
