*Cetli* is Hungarian for the small slip of paper you scribble your shopping list on.

## Features in version 0.2.0

- **Multiple lists:** create, rename and delete; long press to select several at once
- **Edit mode:** type an item and press Enter; the keyboard stays open
- **Shopping mode:** tap an item as it goes into the basket; it is struck through but stays readable
- **No duplicates:** an item already on the list is not added again
- **Sorting** per list: order added, name A–Z or Z–A
- No internet permission, no account, no ads

## Planned

- Sharing a list as a `.cetli` file and merging it on another phone
- A catalog of common items with autocomplete (in progress for version 0.3.0)

## Status

Version 0.2.0 is the first installable beta. The APK can be downloaded from the GitHub releases page. Requires Android 8.0 or newer on a 64-bit phone.
