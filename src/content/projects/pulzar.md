## Features

- **Manual entry:** date, time, systolic and diastolic pressure, optional pulse and a note
- **Table** of the readings by week, month, year or all time, with average, minimum and maximum
- **Chart** of the daily average systolic and diastolic values, with reference lines
- **PDF report for the doctor** for any date range, with a chart and/or a table, printable on A4
- **Backup and restore** of all readings in a single file
- All data stays on the phone; the app does not request internet access

## Status

Version 1.0.0 is the first stable release, and the project is complete. The APK can be downloaded from the GitHub releases page. Requires Android 8.0 or newer on a 64-bit phone.
